One threshold.
Different consequences.

In this experiment, I explore how a decision threshold changes false alarms, missed cases and the cost of errors, using a fixed synthetic dataset.

The question

What does accuracy leave out?

For the same set of scores, changing a threshold changes which samples receive a positive prediction. I use this experiment to make those decisions visible and compare them with an always-negative baseline.

The 80 samples and labels are synthetic. This experiment explores decision rules; no model was trained, and scores are not calibrated probabilities.

Method & evidence

A repeatable experiment.

How the data is made

A deterministic pseudo-random generator starts at seed 314159. Each score is an integer from 0 to 100 divided by 100. The actual label is 1 when score + (random − 0.5) × 0.9 ≥ 0.53, otherwise 0. This deliberately creates overlapping classes. Refreshing the page reproduces all 80 samples.

How the metrics work

  • Accuracy: (TP + TN) / all samples.
  • Precision: TP / (TP + FP).
  • Recall: TP / (TP + FN).
  • Specificity: TN / (TN + FP).
  • F1: 2TP / (2TP + FP + FN).
  • Error cost: FP × false-positive cost + FN × false-negative cost.

Correct decisions have zero cost in this simplified calculation. F1 is displayed as a percentage on the same scale as the other ratios.

An experiment to try

Start with equal error costs. Find a threshold that reduces total errors, then increase the false-negative cost. Does the threshold you prefer change? Compare the resulting confusion matrices and costs.

Limits of the demonstration

The labels depend on the generated scores by design. This is neither an independent test set nor evidence of model performance on real data. Choosing a threshold here only describes these 80 samples. There is no uncertainty estimate, subgroup assessment, calibration analysis or external validation.

Costs are assumptions for exploration. There is no universally best threshold: the appropriate choice depends on the application, evidence and consequences.
