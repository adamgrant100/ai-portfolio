03 WORKING PROTOTYPES

These projects take ideas from my taught modules into small, interactive experiments. Each includes a working demo, source code and notes on its methods and limitations.

The scenarios and datasets are synthetic, and the projects are separate from my assessed coursework.

The projects run directly in your browser. Inputs can be changed, outputs can be inspected and source code is available on each project page.
